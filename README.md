# 🎮 Hangman Game

## 📌 Project Overview

This project is a console-based **Hangman Game** developed in Python as part of the **CodeAlpha Python Programming Internship**.

The objective of the game is to guess a randomly selected word one letter at a time before running out of six incorrect attempts. The game provides an interactive command-line experience with input validation, ASCII Hangman graphics, and a replay option.

---

## 🚀 Features

- 🎯 Random word selection from predefined words
- 🔤 Letter-by-letter word guessing
- 💀 Six incorrect attempts allowed
- 🎨 ASCII Hangman graphics
- ✅ Input validation
- 🔁 Play Again option
- 📋 Displays guessed letters
- 🎉 Win and Game Over messages
- 🧹 Clean and modular Python code

---

## 🎮 Game Rules

- A random word is selected.
- Guess one letter at a time.
- Each incorrect guess decreases the remaining attempts.
- The game ends when:
  - You guess the complete word 🎉
  - OR all six attempts are used 💀
- After the game ends, you can choose to play again.
